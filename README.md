# 🌍 Radio Earth — Global Web Tuner

**Radio Earth** — интерактивный 3D-веб-глобус для прослушивания радиостанций со всего мира в режиме реального времени. Проект вдохновлен эстетикой *Radio Garden* и построен на современном векторном стеке **MapLibre GL JS** с GPU-ускорением, глубокой космической темой и интерактивным прицелом-тюнером.

---

## ✨ Ключевые возможности

- 🌐 **3D Векторный глобус**:
  - Нативная проекция сферы (`projection: 'globe'`) на базе **MapLibre GL JS**.
  - **Естественный теневой рельеф (Shaded Relief / Topography)**: глобальный слой реального географического рельефа Земли (*ESRI World Shaded Relief*), деликатно проявляющий горные системы (Урал, Кавказ, Альпы, Гималаи, Анды, Кордильеры), возвышенности и речные долины с сохранением цвета стран (`rgb(47, 49, 54)` в тёмной теме).
  - **3D-эффект береговой линии**: внутренние тени вдоль берегов континентов, создающие ощущение объёмного шельфа.
  - **Планетарная координатная сетка (градусная сетка)**: аккуратные пунктирные параллели и меридианы каждые 30°, подчеркивающие геометрию сферы.
  - Векторные карты **Carto Dark Matter** (тёмная тема) и **Carto Positron** (светлая тема).
  - Отсутствие тяжелых Three.js циклов и сотен DOM-элементов — рендеринг 100% выполняется векторными слоями WebGL.

- 🎯 **Интерактивный прицел (Radio Garden Style)**:
  - Компактный тактический видоискатель по центру экрана (диаметр 56px).
  - **Автоматический захват при остановке**: во время вращения глобуса воспроизведение не прерывается; через 350 мс после отпускания мыши прицел сканирует пространство под собой.
  - **Плавное центрирование**: камера кинематографично и бесшовно доворачивается (`easeOutCubic`), помещая точку станции строго в центр перекрестия.
  - **Магнитный захват**: если в круге нет станций, прицел плавно примагничивается к ближайшей станции в окрестности.

- 🟢 **Органическая иерархия точек станций**:
  - Каждая точка на карте — город с радиостанциями, светящийся изумрудным цветом (`#16C683`).
  - Размер точки динамически масштабируется в зависимости от числа станций:
    - **1 станция**: аккуратная миниатюрная точка.
    - **2–5 станций**: средняя точка.
    - **6–19 станций**: крупная заметная точка.
    - **20+ станций**: большой светящийся радиоузел мегаполиса.

- 📻 **Богатая база станций и отказоустойчивость**:
  - Интеграция с открытым каталогом **Radio Browser API** с фильтрацией по валидным GPS-координатам и защищенным HTTPS-потокам.
  - Загрузка **~2 800 live-радиостанций** в **1 250+ городах** по всему миру.
  - Автоматический failover между гео-зеркалами (`de1`, `nl1`, `at1.api.radio-browser.info`).

- 🎵 **Модульный аудиоплеер**:
  - Поддержка форматов MP3, AAC, а также HTTP Live Streaming (`.m3u8` via **Hls.js**).
  - Нижняя панель управления с регулировкой громкости, индикатором битрейта, страны и статуса потока.
  - Выдвижное боковое меню (`CityStationsDrawer`) со списком всех станций выбранного города.
  - Функция **Random Tune** для мгновенного перелета в случайную точку планеты.

- 🌗 **Светлая и темная темы (Dark / Light)**:
  - **Темная тема по умолчанию**: звездный космос с туманностями, 400+ мерцающими звездами и метеорами, карта Carto Dark Matter.
  - **Светлая тема**: чистый, нейтральный студийный градиент без звезд, дневная векторная карта Carto Positron и светлый глассморфизм интерфейса.
  - Кнопка быстрого переключения темы (Солнце ☀️ / Луна 🌙) в верхнем правом углу.
  - Сохранение выбранной темы в `localStorage` (`radio_earth_theme`).

- 🌐 **Мультиязычность и локализация (RU / EN)**:
  - Автоматическое определение языка системы и браузера при первом посещении (`navigator.language`).
  - Кнопка быстрого переключения языка (`RU` / `EN`) в правом верхнем углу интерфейса.
  - Сохранение пользовательского выбора в `localStorage` (`radio_earth_lang`).
  - Полный перевод всех экранов: HUD-телеметрия, статус потока, боковая панель станций, экраны загрузки и сбоя сети с поддержкой корректных склонений числительных в русском языке.

- ❤️ **Избранное (Favorites) с мгновенным перелетом**:
  - Быстрое добавление любой радиостанции в избранное одним кликом по «сердечку» в плеере или в списке города.
  - Сохранение избранного в `localStorage` (`radioearth_favorites_v1`) с сохранением метаданных и GPS-координат.
  - Выдвижная панель сохранённых станций с бейджем-счётчиком в HUD, поиском по названию и жанру, и кинематографичным перелетом камеры к станции при воспроизведении.

- 🔗 **Deep Linking и шеринг станций**:
  - Полноценная поддержка прямых ссылок через URL-хэш вида `/#/station/:id` (совместимо со статическим хостингом GitHub Pages).
  - При открытии ссылки глобус автоматически и плавно прилетает в нужный город и запускает трансляцию потока.
  - Кнопка «Поделиться» (Share) в плеере для быстрого копирования прямой ссылки в буфер обмена с анимированной подсказкой.

- 🔍 **Глобальный поиск (`Cmd+K` / `Ctrl+K`)**:
  - Командная палитра быстрого поиска по названию станции, городу, стране и жанрам (Jazz, Techno, Classical, Rock, Ambient и др.).
  - Мгновенный автокомплит, управление клавишами со стрелками (↑/↓) и Enter для быстрого выбора.
  - Автоматическое центрирование глобуса и запуск потока при выборе результата.

- 🛰️ **HUD Телеметрия**:
  - Отображение текущих координат прицела (широта, долгота) и высоты/зума в реальном времени.
  - Счетчики обнаруженных городов и доступных частот.

## 🛠 Стек технологий

- **Фронтенд**: React 18, TypeScript, Vite
- **Картография & 3D**: MapLibre GL JS (v6+), Carto Dark Matter Vector Tiles
- **Аудиодвижок**: HTML5 Audio API + Hls.js
- **Стилизация**: Tailwind CSS, CSS Custom Properties
- **Иконки**: Lucide React

## 🚀 Быстрый старт

### Требования
- **Node.js** версии 18.0 или новее
- Менеджер пакетов **npm** (или yarn / pnpm)

### Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd RadioEarth
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки**:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу: [http://localhost:3000](http://localhost:3000)

4. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
   Скомпилированные статические файлы будут находиться в директории `dist/`.

### 🚀 Автоматический деплой на GitHub Pages

Проект полностью настроен для публикации на **GitHub Pages** через GitHub Actions:

1. Запушьте проект в ваш репозиторий на GitHub:
   ```bash
   git push origin main
   ```
2. Откройте репозиторий на GitHub и перейдите в **Settings** ➔ **Pages**.
3. В выпадающем меню **Source** выберите:
   **GitHub Actions** (вместо *Deploy from a branch*).
4. Готово! При каждом пуше в ветку `main` workflow `.github/workflows/deploy.yml` автоматически соберет проект и опубликует его по адресу:
   `https://<ваш_логин>.github.io/<имя_репозитория>/`

## 🎮 Управление

| Действие | Управление |
|---|---|
| **Вращение глобуса** | Зажать левую кнопку мыши / перетаскивание пальцем |
| **Приближение / Отдаление** | Колесо мыши / жест pinch-to-zoom |
| **Автоматическая настройка** | Отпустить глобус над желаемым регионом |
| **Быстрый выбор станции** | Прямой клик левой кнопкой мыши по любой точке на карте |
| **Случайная станция мира** | Кнопка **СЛУЧАЙНО** / **RANDOM** в правом верхнем углу |
| **Смена темы (Светлая / Темная)** | Кнопка ☀️ / 🌙 в правом верхнем углу |
| **Переключение языка** | Кнопка **RU / EN** в правом верхнем углу |
| **Список станций города** | Клик по названию города или кнопке **ВСЕ СТАНЦИИ** на нижней панели |
